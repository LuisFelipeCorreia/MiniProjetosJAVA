# Caixa Eletrônico - Conta Bancária (Mini Projeto 1)

Este é um projeto desenvolvido em Java utilizando a biblioteca Swing para a interface gráfica. O objetivo principal foi aplicar os conceitos de **Programação Orientada a Objetos (POO)**, especificamente o **Encapsulamento**, para proteger o saldo da conta contra operações inválidas.

## 🛠️ Tecnologias Utilizadas
- Java (JDK)
- Java Swing (Interface Gráfica)

## ⚙️ Como executar o projeto

Para testar a aplicação no seu computador, siga os passos abaixo:

1. Faça o clone deste repositório na sua máquina local:
   `git clone https://github.com/LuisFelipeCorreia/MiniProjetosJAVA.git`
2. Abra a pasta do projeto (`01_ContaBancariaJava`) numa IDE de sua preferência (VS Code, Eclipse, IntelliJ, etc.).
3. Certifique-se de ter o **Extension Pack for Java** instalado (se usar o VS Code).
4. Localize o ficheiro `App.java` (onde está o método `main`).
5. Execute o `App.java` (clicando em "Run" ou "Run Java").
6. Uma janela pop-up pedirá o nome do titular da conta. Digite um nome e clique em OK.
7. A interface do Caixa Eletrônico será aberta para que você possa testar os depósitos e saques!
